# fo4-mod-qa
A learning project: build a small Fallout 4 mod and test it like a real product.

## Goals
- Learn the Fallout 4 modding pipeline (Creation Kit, F4SE, Mod Organizer 2, xEdit)
- Write a test plan and file bug reports in Jira
- Build Python tools to inspect and validate mod files

## Status
Setting up and linking Jira to Github and creating a project structure.
